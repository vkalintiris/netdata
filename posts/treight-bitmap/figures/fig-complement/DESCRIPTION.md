# fig-complement — dense sets store their holes; and/or dispatch by De Morgan

## Intent

The blog's §"Dense sets: store the holes, dispatch by De Morgan": the
`Bitmap` layer over the raw tree — an `inverted: bool` that flips meaning
between "stored tree = members" (N) and "stored tree = holes" (I) — and the
match-arm tables that turn every `and`/`or` into ONE raw walker call.

Placement: draft §4.6 (Dense sets: store the holes, dispatch by De Morgan).

## The verified data

Worked example (universe 64): a dense set with 60 members whose holes are
{9, 25, 26, 60}.

- Hole digits (base 8): 9 = 0o11 → leaf 1 bit 1; 25 = 0o31 → leaf 3 bit 1;
  26 = 0o32 → leaf 3 bit 2; 60 = 0o74 → leaf 7 bit 4.
- Stored (inverted) tree: root `8a` (children {1, 3, 7}), leaves
  `02` (hole 9), `06` (holes 25, 26), `10` (hole 60) → bytes `8a 02 06 10`.
  A 60-member set in 4 bytes.
- Dispatch tables (bitmap.rs doc comments on `and`/`or`):

```
and(A,B)            raw op → result      or(A,B)            raw op → result
N & N               intersect → N        N | N              union → N
N & I               A − B     → N        N | I              B − A → I
I & N               B − A     → N        I | N              A − B → I
I & I               union     → I        I | I              intersect → I
```

- Short-circuits: ∅ ∧ x = ∅ (no bytes); U ∧ x = x (bytes copied);
  ∅ ∨ x = x (copied); U ∨ x = U (nothing). `and_not(a, b)` =
  `a.and(complement(b))`.
- Read-side: `contains` = raw lookup XOR flag; `len` = universe − stored
  population; `range_cardinality` = range len − stored count in range;
  inverted ITERATION is O(universe) (ComplementIter walks everything,
  skipping stored holes).

## Manual-recreation guide (typst)

1. Fixed canvas 940 × 640 pt; four panels (representation top-left, De
   Morgan top-right, short-circuits bottom-left, read-costs bottom-right).
2. The two 64-cell strips are `#stack(dir: ltr)` of `vcell` boxes (5.6 pt
   wide), generated by `..range(64).map(i => vcell(i, i not in holes, blue))`
   — change the `holes` array at the top of the file and both strips, the
   byte chips, and the annotation all need recomputing (see "verified data").
   Blue = member cells (real set); vermillion = stored cells (the holes
   ARE the stored tree's members). White gaps in strip 1 = the holes.
3. The dispatch table is one `#grid` with 6 columns (and-row / or-row side
   by side); `N`/`I` letters carry the distinction in text — the figure
   stays legible in greyscale and for colorblind readers.
4. Escapes: `\[` for literal brackets; close every `#text(...)[...]`
   bracket; long footers wrapped in `#box(width: 900pt)`.
5. The ∅/U short-circuit table uses `∅` (empty) and `U` (full universe).

## Verification performed

- Compiled clean (typst 0.14.1); 144 ppi PNG = 1880 × 1280.
- `verify_layout.py`: no clipping, no region collisions; ASCII preview
  confirmed the dense strip has gaps exactly at positions 9, 25, 26, 60 and
  the holes strip is otherwise empty.
- Byte string `8a 02 06 10` re-derived from the hole set by hand (digits
  above) and cross-checked against `from_sorted_iter` semantics.

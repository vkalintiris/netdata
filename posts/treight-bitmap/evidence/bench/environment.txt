## Machine sharing / noise

The box is SHARED with other agents on the same blog task (corpus capture,
writing, diagrams) and other builds during the runs. Timings are criterion
medians over 50 samples (1s warmup, 2s measurement per bench); medians are
robust to transient load but absolute numbers carry shared-machine noise —
compare relative orderings, not sub-percent deltas. RAM was ~17/31 GiB used
at run time.

## Build note

This host wraps `cc` as ccache with a read-only default cache dir, so every
cargo invocation in the evidence commands below ran with
`CCACHE_DIR=/tmp/nd-bp-ccache`. This affects BUILD times only, never bench
timings (cargo bench rebuilds happen before timing starts).

## Exact commands (reproduce from the repo root)

```bash
export CCACHE_DIR=/tmp/nd-bp-ccache

# 1. Derive posting lists (production flatten path — see TRACE.md)
for c in certstream jetstream mixed; do
  cargo run -q -p treight-bench --bin treight-derive -- \
      --corpus data/corpus/$c-250k.jsonl.gz --out data/derived/$c-250k
done

# 2. Index-footprint totals (treight vs roaring bytes over all posting lists)
for c in certstream jetstream mixed; do
  cargo run -q -p treight-bench --bin treight-footprint -- \
      --derived data/derived/$c-250k \
      --json posts/treight-bitmap/evidence/bench/totals-$c-250k.json \
      --md   posts/treight-bitmap/evidence/bench/totals-$c-250k.md
done

# 3. CPU benches (criterion; per-corpus runs write bench-fixtures.json into
#    the derived dir; raw criterion output under src/crates/target/criterion)
TREIGHT_BENCH_DERIVED=$PWD/data/derived \
  cargo bench -p treight --features roaring --bench vs_roaring

# 4. Harvest medians into evidence
python3 posts/treight-bitmap/evidence/bench/harvest.py \
    --derived data/derived \
    --criterion src/crates/target/criterion \
    --out posts/treight-bitmap/evidence/bench

# 5. (stretch) real .sfst build + derivation cross-check — see sfst-stretch.md
cargo run -q -p treight-bench --bin treight-sfst -- \
    --derived data/derived/certstream-250k --out data/derived/sfst-stretch
```

Derived caches live under gitignored data/derived/<corpus>/ (format
documented in src/crates/treight-bench/src/lib.rs; version-tagged in
meta.json). Corpora are public internet data but contain personal data
(DIDs, handles, cert subjects); only aggregates are committed.
